# JenAI v2.4.1

v2.4.1 是不改變機器人功能語意的維護性版本，重點是縮小大型函式、
讓核心規則可獨立測試，並降低 TUI 與導航安全閘門的修改風險。

## 程式結構

- 將 slash 指令選單的比對、參數提示、選取與補完規則抽成純狀態模組。
- 將 slash grammar 與 handler 選擇抽成純分派模組，並以契約測試確保目錄中的
  每個指令都有實際 handler。
- 將資料權限 hardening plan 的組裝拆成單一介面的 builder，保留原有檢查順序、
  拒絕原因與受保護檔案規則。
- 將 Navigation Gateway 的場域設定檢查、live map 驗證與 mismatch 判斷分離；
  不可驗證時仍維持 fail-closed 與誠實回報。
- 移除只為舊測試存在的 TUI 相容屬性與死碼。
- 補回 Sites 官方 starter 應提交的 build plugin，修正乾淨 clone 後文件網站無法建置。

## 客觀變化

- `tui/app.py` 由 1,357 行降至 1,251 行。
- 三個目標函式分別由 66、103、116 行降至 6、3、21 行；細節移入具名、
  可單獨測試的深模組或內部 helper。
- production code 的 cyclomatic complexity 仍全部不超過 10。

## 驗證

- Ruff format 與 lint 全部通過。
- Strict mypy 通過 129 個 production source files。
- 完整 1,076 項 pytest 測試通過。
- TUI 真實 Textual test harness 驗證指令選單、補完、分派與既有互動。
- Navigation Gateway、Site identity／migration 與 area-patrol adapter 契約測試通過。
- wheel 與 sdist 建置、乾淨 wheel CLI smoke test 通過。
- 文件網站 typecheck、正式 build 與 3 個渲染頁測試通過。

## 明確未改動

- 沒有修改 Nav2 goal、到點容差、Twin policy、watchdog、急停或批准語意。
- 沒有把 LLM 移入即時控制迴路。
- 大型 ROS sidecar 與 Isaac HIL 驗收器仍保留為整合邊界；本版不為追求檔案行數而
  拆散需要整體審閱的 I/O 與驗收流程。
