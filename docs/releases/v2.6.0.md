# JenAI v2.6.0

v2.6.0 打磨第一次啟動與操作員工作流程，將 WebUI 提升為可重新整理、可稽核且
安全綁定動作內容的監控介面，並加入 NXDog 的實驗性唯讀觀測整合。既有
Claude Code 風格 TUI、Nav2／AMCL 演算法與導航參數維持不變。

## 第一次啟動與 TUI

- Setup wizard 在單一欄位驗證失敗後保留先前答案，並提供 URL 檢查、隱藏式 API key
  輸入、`0600` 原子寫入與清楚的下一步。
- 自訂 `--config` 現在預設載入同目錄 `.env`；既有部署可搬移 `.env`、設定
  `JENAI_ENV_FILE`，或將必要值 export 到 shell。
- 保留已核准的 TUI layout、吉祥物、composer、approval hierarchy、色彩與 responsive
  breakpoints，只改善臺灣繁體中文操作文案、Quick Start 與批准語意。
- 文件網站改善導覽、鍵盤搜尋、手機版選單與版本顯示，不改變 Runtime 或導航行為。

## WebUI 操作生命週期

- WebUI 可在重新整理後重建 current-service runs、pending approvals、工具時間軸、證據、
  terminal outcome 與 Task Receipt；non-terminal／pending runs 不會被歷史筆數上限隱藏。
- 可重新整理的批准使用不可變、經脫敏且適合操作員閱讀的 preview；完整動作與 canonical
  digest 只保存在 server。preview 缺失或與 server-held action 不一致時 fail closed，不能批准。
- RunStore 使用同步保護與 detached snapshots，批准、工具與 run 的主要 lifecycle transition
  以原子操作更新，降低多個 HTTP request 讀到半完成狀態的風險。
- WebUI STOP 現在會搶佔執行中的 confirmation、取消 coroutine、等待有界 cleanup、推進
  process-local safety epoch，並禁止舊動作在 STOP 後以 late success 覆寫結果。
- Provider 的自訂 `api_key_env`、`JENAI_WEB_TOKEN`、Bearer token 與常見密碼格式在進入
  RunStore、monitoring projection 與 Task Receipt 前即脫敏；Browser 不取得 raw action digest。

## NXDog 唯讀觀測

- 新增 opt-in 的實驗性 NXDog HTTP observer，透過 `JenAI doctor` 讀取 health、ready、
  current map、pose、velocity 與 charging 狀態，並保留各 endpoint 的部分失敗證據。
- Robot HTTP traffic 停用 ambient proxy、拒絕 redirect，並對 URL、payload size、JSON、
  非有限數字與 timeout 採 fail-closed 驗證。
- API 可達與 vendor `ready_flag` 不等於定位或導航 ready；vendor map name 也不取代
  JenAI Site Profile 的 cryptographic map identity。
- 本版沒有新增 NXDog Agent tool、TUI／MCP action、Navigation Gateway motion path、
  `/navigate`、`/stop`、`/set_cmd_vel`、姿態、充電控制或地圖 mutation。

## 架構方向

- ADR 0005 固定 NXDog HTTP adapter 的 observation-only 邊界。
- ADR 0006 接受未來單一 authenticated high-level HTTP Robot Runtime authority 的方向；
  本版尚未實作 Runtime server，也沒有遷移 TUI、WebUI、MCP 或既有 motion path。
