# JenAI v2.5.1

v2.5.1 聚焦於產品級急停、導航終點驗證與 Isaac Sim／Nav2 啟動可靠性；
所有成功狀態都必須建立在可驗證回執上，不能以文字推定。

## 安全停止與 TUI

- 明確的自然語言急停現在與 `/stop` 具有相同的最高排程優先權：先送停止、取消目前任務、清空待執行佇列，再完成最終停止確認。
- 急停執行移至不依賴 LLM provider 或 Agent SDK 的安全服務；模型失效時仍保有確定性停止路徑。
- 新增型別化 `HaltReceipt`；只有 ROS bridge 確認零速度已送達後，系統才會回報停止成功。
- 保守化急停意圖辨識，避免將「導航到停車場」或「停車位在哪裡」誤判成致動命令。
- 支援「先停車，再回報機器人狀態」等複合要求，狀態快照只在停止送達後擷取。

## 導航精度與啟動可靠性

- JenAI 對 Nav2 成功結果的產品預設二次驗證收緊為 0.05 m 位置誤差與 0.15 rad 朝向誤差；設定可依場域收緊，但不可放寬產品上限。
- 一鍵 Nav2 啟動在發現既有 session 時不再執行失敗清理，避免第二次啟動誤殺正在使用的導航服務。
- 維持 launch-time `general_goal_checker.stateful=false`，讓 Ackermann 底盤對齊朝向期間持續重驗位置。
- 新增有界近端停滯恢復：只有急停送達且舊 Nav2 goal 取消獲確認後，才允許一次較短的同目標重送；最終仍須通過停止後 TF 的 0.05 m／0.15 rad 契約。
- DWB `vtheta_samples` 預設調整為奇數 15，確保速度取樣包含零角速度；維持 `min_vel_x=0.0`，避免前向 180° 雷射配置下以倒車繞過失敗。
- 一鍵啟動新增 Nova Carter 模擬 AMCL 精度 profile：`alpha1..5=0.01`、`update_min_a/update_min_d=0.02`；啟動後會讀回並 fail closed 驗證實際參數。這些值不適用於未校正的實體平台。
- 操作指南不再要求每輪無條件 Stop／Play：車輛未卡牆、定位健康且舊 goal 已清除時，先 `/dock` 再 restart Nav2 即可；卡牆、模擬時間重置、定位漂移或固定基準重播才需重新 Play。
- `JenAI`、`jenai` 與 `uv run JenAI` 在尚無可用 ROS 時會自動載入 ROS 2 Jazzy 與設定的 workspace；不再要求 wheel 使用者以 symlink 或手動 source 才能進入 ROS 功能。直接操作 `ros2`／RViz2／HIL 的父 shell 仍須明確 source。
- `/route` 批准卡顯示具名目標與座標，不再暴露 Python dict；無法解析地點時 fail closed，不送導航目標。

## 已知邊界

- `/dock` 驗證的是導航至註冊停靠姿態；Isaac Sim 尚無充電接點回授。
- 5 cm／0.15 rad 是對外成功判定上限，不等於充電座機械對位保證；真實充電仍需視覺、標記或充電回授閉環。
