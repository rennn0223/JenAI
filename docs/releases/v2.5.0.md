# JenAI v2.5.0

v2.5.0 將 JenAI 的受監督導航、Agent 執行流程、使用者可見語言與
Isaac Sim／Nav2 驗收提升為一致、可重現且誠實回報的產品路徑。

## 導航與 Isaac Sim

- 新增 ROS 2 Jazzy／Isaac workspace／Nav2 一鍵啟動與重新啟動腳本。
- Nav2 一般導航預設使用 0.05 m 位置與 0.15 rad 角度容差，避免過度收緊造成已在目標附近卻持續 recovery 的假性失敗。
- 導航停止後使用新的 `map → base_link` TF 快照驗證最終位置與角度；缺少新鮮回授時維持 fail-closed，不把接近目標誤報為成功。
- 導航逾時改由 `[vehicle].nav_timeout_s` 設定，預設 240 秒，不再硬編碼 600 秒。
- 定位短時間大幅跳變時取消導航並送出停止命令，避免重播或重定位期間繼續移動。
- 補強長任務的 ROS 節點識別與 latched map observation，降低重複節點與地圖一次性資料遺失造成的不穩定。

## Agent 與 TUI

- 修正批准、取消、恢復與任務所有權生命週期，避免使用者批准後 TUI 中斷或舊任務殘留。
- 對明確且純唯讀的位置、LaserScan 與 Nav2 狀態查詢加入確定性快速路徑，不必等待本地大型模型；涉及決策或致動的要求仍走完整 LLM 與批准邊界。
- 持續感知與視覺分析明確區分 `completed` 與 `unavailable`，沒有證據時不宣稱分析成功。
- 使用者可見文字經臺灣繁體中文正規化；程式碼、路徑、URL 與識別碼保持原樣。

## 文件與驗收

- 新增使用者驗收目錄，整理 TUI、自然語言、Nav2、巡邏、視覺與失敗情境的手動測試方式。
- 更新 Quick Start、Isaac Nav2 設定、技術指南、HIL 驗收與文件網站。
- `UNVERIFIED_SESSION_OBSERVATION`：發佈前操作紀錄曾抄錄 `map_left_down` 為
  0.041 m／0.140 rad、`dock` 為 0.035 m／0.068 rad；發佈後稽核發現未同步封存
  對應原始 artifact、SHA-256 與 execution revision，故這四個數字**不可作為正式可稽核 HIL 證據**。
  v2.5.0 的正式可追溯導航主張仍以 `EVIDENCE_LEDGER.md` 已登錄且有雜湊的場次為準。

## 驗證

- Ruff format 與 lint 通過。
- Strict mypy 通過全部 production source files。
- 完整 pytest 與 branch coverage 閘門通過。
- Python 3.12、3.13、3.14 CI 全部通過。
- wheel／sdist、乾淨 wheel 生命週期、網站 production build、dependency audit 與 SBOM 皆通過。

## 已知邊界

- `/dock` 目前驗證的是導航至註冊停靠姿態；Isaac Sim 尚無充電接點回授。
- 若真實產品要求穩定低於 5 cm 的充電對位，應加入視覺／標記／充電回授與專用低速 docking controller，不以過度收緊一般 Nav2 容差代替。
