# JenAI v2.4.0

**v2.4.0 hardens the workflow-first architecture into a smaller, reviewable,
and truth-preserving release candidate without moving navigation or motion
control into the LLM.**

## Architecture and maintainability

- The semantic area-patrol capability is now product-surface-neutral. The
  OpenAI Agent SDK is a thin adapter; TUI, Web, CLI, and future interfaces can
  share the same deterministic service without importing one another.
- A typed minimal run-context protocol replaces a dependency on the full Agent
  context. Architecture regression tests preserve the JenAI/JenCore/JenROS
  responsibility boundary inside the monorepo.
- Nav2 path-result translation was extracted into a pure module with focused
  tests. Long functions across ROS, Twin Gate, TUI, WebUI, daemon, experiments,
  and acceptance code were decomposed while preserving their public contracts.
- Ruff now enforces a maximum cyclomatic complexity of 10 for production code.
  Strict mypy continues to cover the entire `src/jenai` tree.

## Honest navigation, cancellation, and UI behavior

- A transient inability to read the active map is reported as temporarily
  unavailable and handled by the workflow's bounded retry policy. A true
  site/map identity mismatch still fails closed.
- Workflow cancellation now produces typed interruption events during an
  inspection point or return-home operation rather than leaking an async
  cancellation through the mission boundary.
- Natural-language patrol routing rejects questions, negated requests, and
  explicit user-ordered waypoint sequences; only complete site-coverage intent
  selects the long-running area-patrol workflow.
- TUI result rendering builds Textual `Content` directly. Untrusted nested
  model/tool output is no longer parsed as Rich markup, while explicitly trusted
  markup remains opt-in.
- Vision normalization filters normal-state prose from anomaly lists while
  retaining concrete observed deviations.

## Validation

- Ruff lint and formatting pass across 231 files.
- Strict mypy passes for 127 production source files.
- All 1,066 pytest cases pass. Overall branch coverage is 79% against a 76%
  gate; the safety chain is 94% against a 90% gate. The semantic patrol workflow
  is 97%, its shared service is 93%, and its Agent adapter is 100%.
- Documentation website typecheck, three rendered-page tests, and production
  build pass, including `/docs/quickstart`.
- Wheel/sdist build, isolated `JenAI version` and `jenai --help` entry points,
  and the locked-runtime dependency audit pass locally.
- A supervised post-fix Isaac Sim/Nav2 run selected one workflow with one
  approval, completed 4/4 required semantic areas, saved 4/4 image evidence,
  reported 100% required observation coverage, and returned to dock at 0.036 m
  position error and 0.150 rad yaw error. End-to-end duration was 795.197 s.
  Post-run `JenAI doctor` passed all configured simulation readiness checks.
- The preceding defect-discovery run honestly returned `PARTIAL_SUCCESS`, 3/4,
  and 75% coverage, exposing the transient-map and final-renderer defects that
  this release fixes.

## Explicit limits

- Semantic area coverage is not geometric or frontier exploration.
- Isaac Sim pose-only docking does not prove physical connector alignment or
  charging-current feedback.
- One full live scenario is descriptive engineering evidence, not a statistical
  reliability benchmark, VLM accuracy study, or cross-platform validation.
- Quadruped execution and persistent event-driven LLM re-entry remain planned,
  not shipped claims.

GitHub CI, merged revision, release assets, dependency audit, SBOM, checksums,
and provenance claims become authoritative only after the corresponding remote
workflows and published release pass.
